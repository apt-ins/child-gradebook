# 学迹界面规范

面向家长与孩子的私人求学档案。浏览考试、回看变化和录入成绩是三个主要任务。

- 视觉：晴空蓝白主色，蓝色总分、浅杏班级排名、淡紫年级排名；深色主题采用靛蓝表面。颜色、边界和阴影由 `xueji.css` 统一管理。
- 字体：本地 D-DIN 数字与系统中文字体，清晰区分标题、数值和辅助信息。
- 成绩：两列紧凑横条，每条依次为彩色科目图标、名称、得分/满分；图标按科目名固定映射，未知科目使用书本图标。点击科目查看历史趋势。
- 考试导航：等宽上一场、下一场按钮，边界处禁用；顶部考试选择条进入总览，避免重复入口。
- 总览：按年级和学期分组的考试网格，展示原始总分、满分与排名；支持临时搜索与筛选，取消不改变当前记录，选择后再应用。手机全屏、桌面居中宽面板。
- 次要内容：编辑入口位于成绩标题右侧，成绩截图位于成绩列表末尾；小记、详情与两场对照位于成绩之后。
- 动效：复用 Motion for Vue 的导航、图表及数字过渡，普通反馈使用 CSS；尊重减少动态效果，不增加动画依赖。
- 可访问性：原生按钮、表单和对话框；总览关闭按钮无焦点边框，键盘操作使用浅色背景提示；关闭后归还焦点。
- 数据与认证：保留独立版密码登录、设置及重置流程。总分只合计已录入科目，不生成成绩、排名或人数分母。

README 图片来自独立版隔离浏览器测试，仅包含小禾示例数据。浏览器验收产物放在 Git 忽略的 `artifacts/` 中。
