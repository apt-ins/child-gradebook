# 学迹界面规范

面向家长与孩子的私人求学档案。浏览考试、回看变化和录入成绩是三个主要任务。

- 视觉：日光底色、墨蓝摘要、青绿交互与低饱和科目色。仅考试摘要使用深色重点表面，小记采用轻柔浅色表面，避免重复卡片。
- 字体：本地 D-DIN 展示数字，中文使用系统字体；数值使用等宽数字特性。颜色、表面、边界和阴影统一由 `xueji.css` 的语义变量管理。
- 结构：桌面侧边导航与考试历史栏；平板使用紧凑导航；手机使用底部导航，成绩先于小记，历史记录横向翻阅。
- 动效：Motion for Vue 处理导航和科目选中位置、分数条、图表点位及线条过渡；数值更新约 460ms，简单交互使用 CSS。不存在额外的 GSAP 或 3D 运行时。
- 可访问性：原生按钮、表单与对话框，图标按钮有可读名称，键盘焦点可见，关闭详情归还焦点。系统减少动态效果设置会关闭非必要移动与图表动画。
- 数据：视图只读取现有接口返回的考试；总分与得分率由已录入科目计算。缺失成绩与排名保持“未记录”，不生成成绩、排名或比较结果。

浏览器验收产物保存在被 Git 忽略的 `artifacts/redesign/`。README 预览使用隔离测试数据，真实用户资料不提交到公开仓库。
